# Naija Newspaper

A mobile-first Nigerian digital publication and public-profile directory.

## Architecture
- Editorial homepage and news feed
- People directory and public profiles
- Claim/verification workflow backed by Supabase
- Article-to-person relationships
- Advertising and campaign infrastructure
- SEO/entity metadata
- Responsive newspaper-style frontend

## Data
Supabase project: `dprulohylwgzmetgrywj`

The frontend uses the project's publishable client key. Database permissions remain enforced by Supabase RLS.
